# Práctica de escritura · VLA TOEFL iBT 2026

Página pública, sin inicio de sesión, con las dos tareas de Writing:

- **Build a Sentence** (práctica con pistas o modo examen, desglose de puntaje y sección «Cómo y por qué empezar la oración»)
- **Write an Email** (6 consignas originales, contador frente a 150 palabras, rúbrica 0–5, tarjetas en español y modelo de respuesta)

Todo el contenido es original de Vancouver Language Academy. La retroalimentación corre en el navegador; no hay servidor ni se guarda el trabajo en una cuenta (solo una tendencia local opcional en este navegador).

## Archivos del sitio

- `index.html`, `styles.css`, `app.js`, `logic.js`, `.nojekyll`

## Publicar en Netlify Drop (2 minutos)

Si hace falta otra copia o un nombre propio (`vla-escritura.netlify.app`):

1. Abre [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Arrastra esta carpeta (o el archivo `escritura-netlify.zip`).
3. Inicia sesión en Netlify para que el sitio no caduque y, si quieres, cámbiale el nombre a `vla-escritura`.
4. La URL queda así: `https://vla-escritura.netlify.app`.
